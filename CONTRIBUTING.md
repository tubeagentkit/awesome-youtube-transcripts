# Contributing

Thanks for helping keep this list useful.

## What belongs here

- The project gets, processes or works with YouTube transcripts or subtitles.
- Open source projects had a commit in the last 12 months.
- It works today. Try it on a public video before you submit.

## How to add an entry

1. Add one line to the right section, in this format:

   ```
   - [Name](https://link) - What it does, in one or two short sentences.
   ```

2. Describe what the project does, not how good it is. Skip words like "best", "fastest" or "free" unless the project's own docs back them up.
3. Keep one entry per pull request so each can be reviewed on its own.

A GitHub Action checks every link on each pull request.
